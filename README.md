# Tehnike-programiranja

Laboratorijske vježbe i zadaće iz predmeta **Tehnike programiranja** na Elektrotehničkom fakultetu Univerziteta u Sarajevu, **Odsjek za Računarstvo i informatiku**.

Cilj predmeta je razvijanje logičkog razmišljanja, rješavanja problema, razumijevanja osnovnih algoritama i usvajanje dobrih programerskih praksi kroz rad u **C++**.
